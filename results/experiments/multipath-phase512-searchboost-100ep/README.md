# Multipath Phase 512 Searchboost 100ep (`multipath-phase512-searchboost-100ep`)

## Overview

This experiment trained the baseline 504-feature `multipath_phase:512` model across 100 epochs on 11.065M weakness-boosted positions using Quantization Aware Training (QAT).

## Specification
* **Architecture**: `multipath_phase:512` (single head)
* **Features**: 504 sparse inputs
* **Hidden Width**: 512 units (SCReLU)
* **Outcome**: Established the 50.8% Claustrophobia / 60.0% Titanium Normal benchmark that anchored subsequent bucketing and model soup iterations.
