# Documentation

Project-level documentation lives in this directory.

- [status.md](status.md) — technical status, measured results, design decisions, and active engineering work.
- [plan.md](plan.md) — roadmap and longer-term design plans.
- [datasets.md](datasets.md) — dataset catalog and data-pipeline reference.
- [engine-lab.md](engine-lab.md) — engine laboratory and CI workflows.
- [local-teaching.md](local-teaching.md) — local teaching and data-generation tools.
- `superpowers/specs/` — dated design and implementation specifications.

Component-specific README files remain next to the component they document.
